# Simple Interest Calculator

A simple Python program that calculates the simple interest based on the principal amount, annual interest rate, and time period.

## Formula

The calculator uses the following formula:

**Simple Interest = (Principal × Rate × Time) / 100**

Where:

* **Principal** is the initial amount of money.
* **Rate** is the annual interest rate in percent.
* **Time** is the investment or loan period in years.

## Example

For example, if:

* Principal = $1000
* Rate = 5%
* Time = 2 years

The simple interest is:

**(1000 × 5 × 2) / 100 = $100**

## Features

* Accepts principal amount, interest rate, and time as input.
* Calculates simple interest using the standard formula.
* Displays the calculated interest clearly.
* Easy to use and understand.
